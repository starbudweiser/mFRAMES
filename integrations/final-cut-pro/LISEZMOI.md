# Final Cut Pro

Dans mFRAMES : **Fichier › Exporter les marqueurs › Final Cut Pro (FCPXML)**, puis Final Cut Pro › Fichier › Importer › XML. Les retours arrivent comme marqueurs (✓ : résolus, ● : ouverts) dans un projet « mFRAMES » ; copiez-les sur votre projet de montage.

Un module intégré à l'interface de Final Cut Pro (Workflow Extension) n'est pas livré dans la 1.0 : il demande une extension signée et validée par Apple. Le pont local (`/v1`) permet de l'ajouter sans toucher à mFRAMES.
